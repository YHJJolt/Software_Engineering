# Installation Guide

1. Download this entire ZIP file.
2. Copy and run the code in SQL.
3. Select SchoolSystem Folder and drop it to the Visual Studio Project path.
4. Under Webconfig, Change Database path to individual database.
5. And run Login page.
6. If NuGet packages error exist, like below >
   <img width="947" height="122" alt="Screenshot 2026-05-02 202952" src="https://github.com/user-attachments/assets/2d7ec7d6-025c-4e75-bdae-f7bd75278288" />
7. Right-click on your Solution (the very top item in the Solution Explorer). Select Restore NuGet Packages >
   <img width="422" height="252" alt="Screenshot 2026-05-02 205235" src="https://github.com/user-attachments/assets/4970a4f3-46d0-4629-9351-84cf550cbdb7" />
8. Wait a few seconds, then try to Rebuild your project.
9. Re-run Login Page. Good to go :)
